Concept 1

Bluetooth Low Energy

A short-range radio for small gadgets — earbuds, beacons, sensors… and our duck.

  • Low power so battery devices last
  • Your phone speaks BLE through nRF Connect
  • Not the same as classic Bluetooth audio pairing

Concept 3

GATT: the duck’s filing cabinet

  • A Service is a folder of related features
  • Characteristics are files in that folder
  • Each file can allow Read, Write, or both

Ignore the long UUIDs. Hunt for labels: STORY, SUBMIT, FLAG, STATUS.

One Primary Service · four named characteristics

Concept 4

Read ↓ vs Write ↑

Read ↓

Ask the duck what it knows. Use on STORY and FLAG.

Write ↑

Send the duck a message. Use on SUBMIT.

Always write as Text (UTF-8) — not Hex.

Setup

Before you start

  • Install nRF Connect (iOS or Android)
  • Turn Bluetooth on
  • Stand near a powered duck
  • Scan for a name like DUCK-YELLOW

Write answers as Text / UTF-8, never Hex.

Open Scanner · look for DUCK-…

Round structure

Three stages — STORY tells you everything

1 · Say hello

Read STORY. Write the greeting word it asks for.

2 · Unscramble

Decode a short Base64 clue (CyberChef works). Write the word.

3 · Right flock

Set the colour STORY names, then write the final word.

After each unlock: read FLAG, then read STORY again for the next clue.

STORY first · FLAG after a correct write

Common gotchas

When it “doesn’t work”

  • Hex vs Text — switch write encoding to Text / UTF-8
  • Wrong characteristic — write only to SUBMIT
  • Didn’t re-read STORY — next stage lives there after unlock
  • Wrong colour — STATUS may say WRONG_COLOUR
  • Stuck connection — Disconnect, then Connect again

Hex looks clever — Text is correct
